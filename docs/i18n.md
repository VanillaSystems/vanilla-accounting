# Languages of the app

The UI speaks German, French, Italian and English. Numbers, amounts and dates keep the Swiss
format in every language: an apostrophe groups thousands, a point marks the Rappen, and a date reads day.month.year. Month names follow the language.

## Which language a person sees

1. The language picked in the header (DE FR IT EN, next to zoom and theme). The browser keeps it.
2. Else `company.language` in `belege.workspace.yaml`. `npm run init` asks for it.
3. Else the browser's language, when the app has it.
4. Else German.

`company.language` also sets the language of the questions an agent asks the owner about an open
case (`processes/new-case.guide.yaml`, rule `nc-language`). Booking texts stay German.

## How it works

- Each language is one file in `src/app/i18n/locales/`. `de.ts` is the source. Every other file
  must have exactly its keys. `tsc` fails on a missing or extra key, and on a call to `t()` that
  leaves out a placeholder.
- A component shows text only through `t('key', { placeholders })` from `src/app/i18n/index.ts`.
  A text that depends on a count is a plural, `{ one, other }`, chosen by `{n}`.
- `tests/i18n.test.ts` checks that each language has German's keys, plural forms and
  placeholders. It also fails when a component writes visible text (JSX text, `title`,
  `placeholder`, `aria-label`, `alert`, `confirm`) without a dictionary.
- The API refuses a change with a German `error` text, which the CLI and tests read, and a `code`
  with `params` (`src/types/api-error.ts`). The UI shows the code in the person's language
  (`errorText` in `src/app/lib/api.ts`).
- Section and rate names that `src/accounting` writes in German (balance sheet groups, VAT
  rates) are translated in the UI by `accountingName()`.

## Add a language

To add Romansh, for example:

1. Copy `src/app/i18n/locales/en.ts` to `src/app/i18n/locales/rm.ts`. The file name is the
   ISO 639-1 code.
2. Set `name` to the language's own name (`Rumantsch`) and `order` to its place in the picker
   (`3` puts it between Italian and English).
3. Translate every value. Keep each `{placeholder}` and each `{ one, other }` pair.
4. Run `npm test`.

The picker, the `company.language` check and `npm run init` find the new file without other
changes.
