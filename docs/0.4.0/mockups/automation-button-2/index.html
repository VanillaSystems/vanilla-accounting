Automation in the bar

Today the button is a 60 px blue disc that sits over the bar and the page. It is the loudest thing on screen even when nothing happens, and it uses the same blue as the page's main button («+ Receipt»), so it looks like an action, not a place. These five try the opposite. Each one fits in the bar, is calm when idle, and stands out by its state: it moves while a run is going and changes colour when something waits for you. Each frame is the real receipts page (demo); only the button differs. Switch the state and the theme above.

Round 4 · a status widget at the foot of the bar

The top of the bar stays for the areas; Automation moves to the bottom as a small widget that shows its state and a key figure or two. A click opens a summary card with the week's figures, what waits for you and «Run now». «Expanded» widens the bar to icon + name, and each widget gets room for a sentence. The chevron under the widget expands and collapses the bar.
