Automatisierung im Vordergrund

Two questions: how the Automatisierung button stands out from the other areas, and what the area shows when you open it. Today the button is one of ten grey 24 px icons and the area opens on an empty pane («Wähle links einen Ablauf…»). Demo data: Muster Kaffee GmbH.

1Where the button goes

In all three, the button is a 64 px circle, wider than the 52 px dock, so it sticks out over the page. It leaves the second group of the dock. Its ring always shows the state: blue arc spinning while a run is going, amber + number when something waits for you, green when everything is done.

2Opening Automatisierung · direction 1: «Leitstand»

The area opens on an overview instead of an empty pane. It answers, in order: what did the app do for me, what waits for me, what is it doing now, what comes next. In the list, every workflow gets a status dot and its next run; the ones that can't run yet move to Einrichten with the button that unlocks them, instead of a grey «noch nicht ausführbar».

The headline is a sentenceWhat the machine did, in words, then the one thing that needs the person. The number that matters most (89 % without you) is the only coloured one.
Questions are answered hereA task carries its answer buttons; one click, no detour through the run. «Wartet auf dich» is what the amber ring on the button counts.
Not set up ≠ broken«noch nicht ausführbar» becomes Einrichten with the next step to unlock it, and a counter of how much of the books still runs by hand.

3Opening Automatisierung · direction 2: «Fliessband»

The same facts drawn as the conveyor the books go through: each stage shows what passed it this period, how much of it went without you, and where something got stuck. Below each stage, the workflows that do the work there; dashed ones still run by hand. This replaces the Prozesskarte's phase view as the home.
